# 游戏列表单行布局与 Mod 拖入导入

移除主界面的 Mod 按钮及其独立管理弹窗，游戏列表和“打开目录”恢复三列单行布局。拖入 .jar 后导入拖入时所选游戏的 mods 目录，可一次拖入多个；每个文件独立处理，部分失败会显示成功和失败数量。同名文件不覆盖。未选择游戏或已有安装/启动请求时先提示用户。

拖入单个 .mrpack/.zip 继续调用现有整合包安装；混合文件或多个整合包明确提示，不忽略额外文件。拖拽提示文字同步更新。
