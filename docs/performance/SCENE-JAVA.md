# 手动场景与 Java 路径切换

- 场景由设置中的四项选择控制，保存后恢复；移除主界面场景按钮与 9 秒轮播。取消或保存失败恢复原设置。
- Java 路径列表随设置保存，兼容旧单路径配置；规范绝对路径、去重，最多保留 64 条。添加、下载和检测的 Java 都可加入列表；切换不会删除其他路径。
- 游戏启动读取合并后的版本元数据（包括加载器继承），优先使用兼容的所选路径，然后尝试保存的路径，再查找系统和托管运行时。路径记录中的版本只用于展示，实际匹配通过 Java 探测缓存及文件指纹确认。
- 启动状态提供实际 Java 路径。缺少对应主版本时提示在设置下载或选择；游戏启动不自动下载 Java。安装器仍保留原来的 Java 解析行为。

验证：`npm run check`（73 个 JS 文件）、`npm test`（227 通过、1 跳过）、`npm run smoke` 均通过。真实 Electron 窗口运行验证了场景预览、Java 路径列表、切换后保存、保留旧路径；六次验证没有渲染错误。继承配置的 Java 8/17/21 选择、失效路径、版本不匹配、托管回退和取消由测试覆盖。

本次未调整启动器初始化时序，未做可比较的启动耗时基准，不宣称启动提速。游戏进程测试使用模拟子进程，未验证真实 Minecraft 进入世界。旧便携 EXE 未重新打包，使用源码 `npm start` 查看这些修改。
