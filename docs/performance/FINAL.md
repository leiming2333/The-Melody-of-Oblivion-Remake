- macOS/Linux 原生构建启动 CI 已配置但尚未执行；Windows ia32/ARM64 未在对应原生硬件运行。
- 微软真实授权及该 Client ID 的 Minecraft 服务资格未验证；认证链路使用模拟服务测试，详见 [登录说明](../microsoft-login.md)。真实 Java 公网下载、四种加载器进入游戏还需用户环境验收。
