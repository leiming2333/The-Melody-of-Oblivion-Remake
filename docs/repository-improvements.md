| --- | --- |
| 独立更新签名 | 已实现 Ed25519 完整包、增量包验签、恢复复验和镜像分发，已登记公钥及 CI 私钥 secret，见[发布签名](release-signing.md)。 |

| 窗口缩放 | 允许调整大小与最大化、设置最小尺寸；采用不透明背景和原生圆角以避免透明窗口缩放兼容问题。 |
| 开发工具链 | engines 放宽至 Node >=24 <27、npm 11.x；提供开发检查和 .nvmrc，CI/正式构建保持固定版本。 |
| README 截图 | 使用当前源码、隔离数据目录重新截取首页与账户界面。 |
| 外部链接 | 仅可信本地页面主框架可经 IPC 打开已知 HTTPS 服务；Microsoft 设备码链接继续由账户服务校验。 |
| 私密漏洞报告 | 保留 SECURITY.md 的入口和邮件后备说明；本次没有更改远端仓库设置，需在 GitHub Security 设置核实启用状态。 |
