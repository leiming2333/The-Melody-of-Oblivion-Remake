WHY REMAKE

为什么重置

旧版的遗憾

曾经的忘却的旋律是许多老玩家的第一款启动器。可惜作者停止了更新，它渐渐消失在版本更迭中，玩家也失去了这个方便顺手的选择。

重置的原则

从零开始，用 Electron 重新构建。紧凑的窗口、场景化的背景、每一个按钮都为启动服务。

回顾经典

重拾这个名字，是为了向那个年代致敬。把当年一键进入方块世界的简单快乐，用今天的技术重新带回来。

FEATURES

核心功能

⇄

版本管理

接入 BMCLAPI 与 Mojang 官方清单，自动选择更快的下载源，本地版本即刻可见。

⬇

高速下载

最高 32 路并发，大文件自动分段并行下载，SHA-1 完整性校验，失败自动切换源。

◆

多加载器

原版、Fabric、Forge、NeoForge 一站式安装，选好版本剩下的交给启动器。

▣

整合包安装

Modrinth .mrpack 与 CurseForge .zip 直接拖入窗口即可识别安装，实例目录互不污染。

☺

账户管理

离线账户与 Microsoft 正版登录并存，令牌系统级加密存储，启动前自动刷新。

☕

Java 托管

严格匹配版本要求的 Java，缺失时自动下载校验过的 Temurin JRE，不动系统环境。

UNDER THE HOOD

技术底座

  • Electron主进程 / 预加载桥 / 渲染层三层隔离，令牌永不进入页面
  • 启动核心版本继承、规则过滤、原生库解压、退出状态回传与临时文件清理
  • 下载器双源并行探测、HTTP Range 分段、可取消任务与临时分段清理
  • 账户体系设备代码授权全链路：Microsoft → Xbox → XSTS → Minecraft Services
